Character Counter

About the Project

The Character Counter is a simple and interactive web project created using HTML, CSS, and JavaScript. It allows users to type a message and tracks the number of characters entered in real time, with a maximum limit of 200 characters.

Features

- Real-Time Character Count: Displays the number of characters typed.
- Remaining Characters: Shows how many characters are left.
- Progress Bar: Visually displays the typing progress.
- Character Limit: Restricts input to 200 characters.
- Warning Message: Displays a warning when the maximum limit is reached.
- Clear Button: Allows users to clear the message and start again.
- Responsive Design: Provides a clean and user-friendly interface.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "character-counter.html" using Live Server.
4. Start typing in the text area and watch the character count update automatically.
